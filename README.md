# Space Defender - Shooting Game (Pygame)

- `tp1/` : TP1, original single-file prototype. Run: `python tp1/game.py`
- `tp2/` : TP2, same game with an OOP structure
  (GameObject base class, Player, Monster, Bullet, Reward, GameBoard, Game) and tests.
  Run: `cd tp2` then `python main.py`. Tests: `pip install -r requirements.txt` then `pytest`.
